# REPORT.md

В данном отчете описаны намеренные мутации кода (красный прогон), доказывающие, что написанные тесты ловят регрессии. Ошибок со стороны ИИ-агента в ходе реализации не зафиксировано.

**Тест:** убрано обрезание пробелов при создании задачи (`//const trimmed = title.trim()`, `const trimmed = title`) → **правило:** тест `R1: createTask обрезает пробелы и отбивает пустое название` + правило в `AGENTS.md`: «Все входные строки в функциях создания/переименования должны проходить через `.trim()` и проверку `isBlankTitle` перед сохранением» → **[улика: fail_a.png, упавшие тесты `expect(createTask(9, "   ")).toBeUndefined()` и `expect(createTask(9, "\t\u00A0")).toBeUndefined()`]**

**Тест:** убрана валидация и обрезка пробелов при переименовании (`//const trimmed = title.trim()`, `const trimmed = title`) → **правило:** тесты `R1: отклоняет переименование в строку из одних пробелов / табуляций / U+00A0` + правило в `AGENTS.md`: «Валидация пустых названий применяется единообразно во всех мутирующих функциях (и создание, и переименование)» → **[улика: fail_b.png, упали 5 тестов блока R1]**

**Тест:** убран фильтр пустых строк в `visibleTasks` (`const nonBlank = tasks // add for (c)`) → **правило:** тесты `R2: не показывает унаследованную пустую строку в фильтре all / open` + правило в `AGENTS.md`: «Фильтр пустых строк (`isBlankTitle`) применяется до ветвления по фильтрам, во всех ветках `visibleTasks` (all, open, done)» → **[улика: fail_c.png, упали 4 теста блока R2]**
