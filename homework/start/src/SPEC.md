# Requirement

**R1.** По issue #7: переименование в строку из одних пробельных символов отклоняется, остаётся прежнее название; пробелы по краям обрезаются. Пробельные: пробел, табуляция, неразрывный пробел U+00A0

**R2.** Доска не показывает пустые строки — **включая строки, сохранённые до исправления** (в данных такая уже есть).

**R3.** Счётчик «Открытых» считает так же, как список: пустая строка не считается открытой задачей.

# Acceptance tests

**R1.** см сами тесты. Проверяется удаление \t, " " и U+00A0 в конце и в начале; проверяется неизменяемость строки при попытке переименовать её в пустую строку (или полностью в пробельные символы). Для этого сначала создаются задачи с нормальными названиями.

**R2.** просто проверка, показывается ли задача во всех фильтрах.

**R3.** проверка как в R2, но немного более разнообразная.

# Non-goals

модель **НЕ** должна добавлять новых фич, кроме R1-R3, модель **НЕ** должна менять дизайн и внешний стиль сайта, модель **НЕ** должна заглядывать в тест и тем более модель **НЕ** должна менять тесты. Также модель **НЕ** должна проводить "улучшение" кода вне R1-R3, даже если в нем есть явные ошибки.

# Files in scope

**Модель должна менять только src/tasks.ts и src/App.tsx.**

# Definition of done

`npm test` зеленый - проходят все тесты.

`npm run` собирается без ошибок

изменены только `src/tasks.ts` и `src/App.tsx`
